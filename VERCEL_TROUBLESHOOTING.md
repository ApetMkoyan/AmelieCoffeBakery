# Решение проблем с загрузкой продуктов на Vercel

## Проблема: Продукты не загружаются на Vercel

Если продукты не загружаются после деплоя на Vercel, выполните следующие шаги:

### 1. Проверьте переменные окружения

В настройках проекта Vercel (Settings → Environment Variables) убедитесь, что добавлены:

- `SUPERVISOR_PASSCODE` - пароль для админ панели
- `MONGODB_URI` (если используете MongoDB) - строка подключения к MongoDB

**Важно:** Убедитесь, что переменные добавлены для всех окружений:
- Production
- Preview  
- Development

### 2. Проверьте логи Vercel

1. Зайдите в Vercel Dashboard
2. Выберите ваш проект
3. Перейдите в раздел "Deployments"
4. Откройте последний деплой
5. Нажмите "View Function Logs"

Ищите в логах:
- `✅ Server initialized successfully`
- `✅ Products loaded: X categories`
- `❌ Error loading products` (если есть ошибки)

### 3. Проверьте данные

#### Если используете MongoDB:
1. Убедитесь, что `MONGODB_URI` правильно настроен
2. Проверьте, что в MongoDB есть данные в коллекции `products`
3. Если данных нет, добавьте их через админ панель или миграцию

#### Если используете файловое хранилище:
1. Убедитесь, что файл `server/data/products.json` существует
2. Проверьте, что файл содержит данные (не пустой объект `{}`)
3. Файл должен быть закоммичен в Git

### 4. Проверьте API endpoint

Откройте в браузере:
```
https://ваш-домен.vercel.app/api/products
```

Должен вернуться JSON с продуктами. Если возвращается ошибка:
- Проверьте логи (шаг 2)
- Убедитесь, что маршруты правильно настроены в `vercel.json`

### 5. Проверьте консоль браузера

1. Откройте сайт на Vercel
2. Откройте DevTools (F12)
3. Перейдите на вкладку "Console"
4. Ищите сообщения:
   - `🔄 Fetching products...`
   - `✅ Products fetched: X categories`
   - `❌ Error fetching products` (если есть ошибки)

### 6. Проверьте Network запросы

1. В DevTools перейдите на вкладку "Network"
2. Обновите страницу
3. Найдите запрос к `/api/products`
4. Проверьте:
   - Status должен быть `200 OK`
   - Response должен содержать JSON с продуктами
   - Если статус `404` или `500` - проверьте логи сервера

### 7. Типичные проблемы и решения

#### Проблема: API возвращает 404
**Решение:** Проверьте `vercel.json` - маршруты должны быть правильно настроены

#### Проблема: API возвращает 500
**Решение:** 
- Проверьте логи Vercel
- Убедитесь, что все зависимости установлены
- Проверьте переменные окружения

#### Проблема: Продукты пустые `{}`
**Решение:**
- Если используете MongoDB - проверьте подключение и данные
- Если используете файлы - убедитесь, что `products.json` содержит данные

#### Проблема: CORS ошибки
**Решение:** CORS уже настроен в сервере, но если проблема остается - проверьте настройки в `server/index.js`

### 8. Пересборка проекта

Если ничего не помогло:
1. В Vercel Dashboard → Settings → General
2. Нажмите "Redeploy" для последнего деплоя
3. Или сделайте новый коммит в Git для автоматического деплоя

### 9. Проверка локально

Для отладки запустите локально:
```bash
npm run dev
```

И проверьте, работают ли продукты локально. Если локально работает, а на Vercel нет - проблема в конфигурации Vercel.

### 10. Контакты для поддержки

Если проблема не решена:
1. Соберите логи из Vercel
2. Сделайте скриншоты консоли браузера
3. Проверьте, что все переменные окружения установлены

## Дополнительная информация

- Все логи теперь выводятся в консоль Vercel
- API endpoint: `/api/products`
- Health check: `/api/health`
- Проверка токена: `/api/supervisor/verify`
