# 🔧 MongoDB: Проблемы с подключением

## Если MongoDB не подключается автоматически

### Шаг 1: Проверьте переменные окружения в Vercel

1. Откройте ваш проект на Vercel
2. Перейдите в **Settings** → **Environment Variables**
3. Убедитесь, что есть переменная `MONGODB_URI`
4. Проверьте, что значение правильное (должно начинаться с `mongodb+srv://`)
5. Если нужно, обновите значение и перезапустите деплой

### Шаг 2: Проверьте Network Access в MongoDB Atlas

1. Перейдите на https://cloud.mongodb.com
2. Войдите в свой аккаунт
3. Перейдите в **Network Access** (в левом меню)
4. Убедитесь, что есть правило, разрешающее доступ отовсюду:
   - IP Address: `0.0.0.0/0`
   - Comment: "Allow from anywhere"
5. Если правила нет, добавьте его:
   - Нажмите **"Add IP Address"**
   - Выберите **"Allow Access from Anywhere"**
   - Нажмите **"Confirm"**

### Шаг 3: Проверьте Database Access

1. В MongoDB Atlas перейдите в **Database Access**
2. Убедитесь, что у вас есть пользователь с правами **"Read and write to any database"**
3. Если пользователя нет, создайте его:
   - Нажмите **"Add New Database User"**
   - Выберите **"Password"** как метод аутентификации
   - Введите имя пользователя и пароль
   - В разделе "Database User Privileges" выберите **"Read and write to any database"**
   - Нажмите **"Add User"**

### Шаг 4: Проверьте Connection String

Ваш `MONGODB_URI` должен выглядеть так:
```
mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/amelie-cafe?retryWrites=true&w=majority
```

Где:
- `username` - имя пользователя из Database Access
- `password` - пароль пользователя
- `cluster0.xxxxx.mongodb.net` - адрес вашего кластера
- `amelie-cafe` - имя базы данных

### Шаг 5: Разбудите кластер вручную (если нужно)

1. В MongoDB Atlas перейдите в **Database** → **Clusters**
2. Найдите ваш кластер
3. Если видите статус "Paused" или "Sleeping":
   - Нажмите на три точки (⋮) рядом с кластером
   - Выберите **"Resume"** или **"Wake Up"**
   - Подождите 1-2 минуты

### Шаг 6: Проверьте логи на Vercel

1. В Vercel перейдите в ваш проект
2. Откройте **Deployments**
3. Выберите последний деплой
4. Откройте **Functions** → **View Function Logs**
5. Ищите сообщения о MongoDB:
   - ✅ "Connected to MongoDB successfully" - всё хорошо
   - ⚠️ "MongoDB connection error" - есть проблема
   - ⚠️ "MongoDB cluster might be sleeping" - кластер спит

## Что я исправил в коде

✅ **Автоматические повторные попытки** - до 3 попыток с задержкой
✅ **Увеличенные таймауты** - до 90 секунд (достаточно для пробуждения)
✅ **Автоматическое переподключение** - при каждом запросе пытается подключиться
✅ **Улучшенное логирование** - показывает, что именно происходит

## Альтернативное решение

Если MongoDB всё равно не работает, вы можете использовать только файловое хранилище:

1. В Vercel удалите переменную окружения `MONGODB_URI`
2. Перезапустите деплой
3. Приложение будет использовать JSON файлы (как раньше)

**Примечание:** На Vercel файлы доступны только для чтения, изменения не сохраняются между деплоями.
