# 📝 Инструкция по обновлению сайта

## ✅ Да, теперь все будет работать!

После настройки MongoDB:
- ✅ Все изменения (фото, цены, продукты) **сохраняются навсегда**
- ✅ Данные не теряются при перезапуске сервера
- ✅ Работает на всех устройствах

## 🔄 Как обновлять сайт

### Простой способ (рекомендуется):

1. **Внесите изменения в код** (на вашем компьютере)

2. **Добавьте в GitHub:**
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push origin main
   ```

3. **Vercel автоматически обновит сайт!** 🎉
   - Обычно это занимает 2-3 минуты
   - Вы получите уведомление на email (если настроено)
   - Проверить можно в Vercel Dashboard → Deployments

### Или используйте скрипт:

Если у вас есть файл `update-github.sh`:
```bash
./update-github.sh "Описание изменений"
```

## ⚠️ Важные моменты

### 1. Переменные окружения
Если вы добавляете новые переменные окружения (например, `MONGODB_URI`):
- Добавьте их в **Vercel** → Settings → Environment Variables
- Они сохраняются между деплоями

### 2. MongoDB данные
- Данные в MongoDB **не теряются** при обновлении кода
- Они хранятся отдельно от кода
- При первом запуске с MongoDB данные из JSON файлов автоматически загрузятся (если коллекции пустые)

### 3. Локальная разработка
- Для локальной разработки используйте JSON файлы (не устанавливайте `MONGODB_URI`)
- Для production на Vercel используйте MongoDB (установите `MONGODB_URI`)

## 📋 Чек-лист перед обновлением

- [ ] Код работает локально
- [ ] Все изменения сохранены
- [ ] Переменные окружения добавлены в Vercel (если нужны новые)
- [ ] Код загружен в GitHub
- [ ] Проверен статус деплоя в Vercel

## 🚨 Если что-то пошло не так

1. **Проверьте логи в Vercel:**
   - Vercel Dashboard → Ваш проект → Deployments → выберите деплой → Logs

2. **Проверьте переменные окружения:**
   - Убедитесь, что `MONGODB_URI` установлена
   - Проверьте, что connection string правильный

3. **Проверьте MongoDB:**
   - Убедитесь, что кластер работает
   - Проверьте Network Access (должен быть разрешен доступ отовсюду)
