# ⚠️ ВАЖНО: Настройка MongoDB для Vercel

## Проблема
**На Vercel изменения в JSON файлах НЕ сохраняются!** При обновлении страницы или перезапуске сервера все изменения теряются.

## Решение: MongoDB Atlas (бесплатно)

### Быстрая настройка:

1. **Создайте аккаунт:** https://www.mongodb.com/cloud/atlas/register
2. **Создайте кластер** (выберите бесплатный M0)
3. **Настройте доступ:**
   - Database Access → создайте пользователя с паролем
   - Network Access → разрешите доступ отовсюду (`0.0.0.0/0`)
4. **Получите Connection String:**
   - Database → Connect → Connect your application
   - Скопируйте строку и замените `<username>` и `<password>`
   - Добавьте имя базы: `...mongodb.net/amelie-cafe?retryWrites=true&w=majority`
5. **Добавьте в Vercel:**
   - Settings → Environment Variables
   - Добавьте `MONGODB_URI` со значением вашей строки подключения
   - Перезапустите деплой

### Подробная инструкция
Смотрите файл `MONGODB_SETUP.md` для детальных шагов.

## После настройки
✅ Все изменения (фото, цены, продукты) будут сохраняться навсегда  
✅ Данные не потеряются при перезапуске  
✅ Работает на всех устройствах

## Локальная разработка
Без `MONGODB_URI` приложение использует JSON файлы (для разработки).
