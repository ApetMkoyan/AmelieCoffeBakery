# 🔄 Миграция данных в MongoDB

## Проблема: Нет продуктов на Vercel

Если после настройки MongoDB на Vercel нет продуктов, нужно мигрировать данные из JSON файлов в MongoDB.

## Решение 1: Автоматическая миграция (при перезапуске)

Данные автоматически мигрируют при следующем деплое, если:
- MongoDB коллекции пустые
- JSON файлы существуют в репозитории

**Что делать:**
1. Убедитесь, что JSON файлы в GitHub репозитории
2. Перезапустите деплой в Vercel (Redeploy)
3. Проверьте логи - должны быть сообщения о миграции

## Решение 2: Ручная миграция через API

Если автоматическая миграция не сработала:

1. **Войдите как супервайзер** на сайте

2. **Откройте консоль браузера** (F12 → Console)

3. **Выполните команду:**
   ```javascript
   fetch('/api/migrate-data', {
     method: 'POST',
     headers: {
       'Content-Type': 'application/json',
       'x-supervisor-token': 'ВАШ_ТОКЕН'
     }
   })
   .then(r => r.json())
   .then(data => console.log('Migration result:', data));
   ```

   Где `ВАШ_ТОКЕН` - это токен, который вы получили при входе как супервайзер.

4. **Или используйте curl:**
   ```bash
   curl -X POST https://ваш-сайт.vercel.app/api/migrate-data \
     -H "Content-Type: application/json" \
     -H "x-supervisor-token: ВАШ_ТОКЕН"
   ```

## Решение 3: Загрузить данные вручную

Если миграция не работает, можно загрузить продукты вручную:

1. **Откройте файл `server/data/products.json`** на вашем компьютере

2. **Скопируйте данные**

3. **Войдите как супервайзер** на сайте

4. **Добавьте продукты через интерфейс** (Студия продуктов)

Или используйте MongoDB Atlas напрямую:
1. Зайдите в MongoDB Atlas
2. Database → Browse Collections
3. Выберите коллекцию `products`
4. Insert Document
5. Вставьте данные из JSON файла

## Проверка

После миграции:
1. Обновите страницу сайта
2. Продукты должны появиться
3. Проверьте в MongoDB Atlas → Database → Browse Collections → products

## Если ничего не помогло

1. Проверьте логи Vercel:
   - Vercel Dashboard → Ваш проект → Deployments → выберите деплой → Logs
   - Ищите сообщения о миграции или ошибки

2. Проверьте MongoDB:
   - Убедитесь, что `MONGODB_URI` правильно установлена в Vercel
   - Проверьте, что кластер работает в MongoDB Atlas

3. Проверьте JSON файлы:
   - Убедитесь, что `server/data/products.json` есть в GitHub репозитории
   - Файл не должен быть пустым

---

**После успешной миграции все продукты будут в MongoDB и сохранятся навсегда!** ✅
