# Админ Панель

Админ панель теперь находится в отдельном файле и доступна по адресу:

**В разработке:** http://localhost:5173/admin.html  
**В продакшене:** https://your-domain.com/admin.html

## Настройка

1. Создайте файл `.env` в папке `server/` со следующим содержимым:
```
SUPERVISOR_LOGIN=ваш_логин
SUPERVISOR_PASSCODE=ваш_пароль
```

2. Установите зависимости для сервера (если еще не установлены):
```bash
cd server
npm install
```

3. Перезапустите сервер, чтобы переменные окружения загрузились.

## Использование

1. Откройте админ панель по адресу `/admin.html`
2. Войдите используя логин и пароль из `.env` файла
3. Управляйте продуктами, заказами и расходами через интерфейс

## Безопасность

- Логин и пароль хранятся в `.env` файле, который не должен попадать в git
- Админ панель полностью отделена от основного сайта
- Все запросы к API требуют токен авторизации
